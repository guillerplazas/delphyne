## Diagnosis and frozen experiment

Existing `Print`, `Check`, `Locate`, prefix inspection and unassisted checking
supply the relevant facts. The prior typed arms never inspected conversion;
Q/F checked only sqrt_pos, and selected advice made no tool calls. Rsqr is
multiplication, while real pow at exponent two reduces to z*(z*1); INR 3 and
the real numeral 3 are not definitionally convertible. The goal separator
`|-` was also misread as a minus sign in prior answers. Preserve existing
rendering and the five-demo bank to isolate this control change.

The old Rsqr witness `exact H.` works without change, so it is not evidence
that the repair enables progress. The induction witness `rewrite IH.; lia.`
and additional IMO-1983 witness `nra.` fail before their change and close the
original focus after it. `preparation_checks.json` records both directions.
No missing-reference/normalization repair or nra admission-guard change is
included. Prior applicability results and guard sensitivity stay unchanged.

The local Delphyne paper (papers/2502.05310v5 (1).pdf, strategy composition and
spending-stream sections) motivates the implementation: inline the existing
repair and ordinary-continuation strategies, use Compute for one canonical
check, and preserve policy-side spending admission. No new prover tool or
orchestrator. Typed Compute reservations are common across new arms. The
checkpoint records zero verifier work and preserves the applicability phase
if the later request is refused; it does not charge verification twice.

## Resource and outcome definitions

Responses, temperature unset, output cap 32768, ReadSkill/SearchRocq/
InspectProofState, incumbent x3 playbook, fixed five demonstrations. At most
four model requests per episode including tool calls; one ordinary proposal
at most in primary, none in Terra. 300 verifier seconds, 60 seconds/512 RPCs
per operation, 8192-byte views, unassisted local checking in every arm.

Fresh local budgets are $0.10 for Luna and $1.00 for Terra. The latter permits
conservative admission at the same output cap; these are matched token/request
limits, not a same-dollar deployment comparison. Stage ceilings override cell
allowances; refusal gives an incomplete panel, not permission for a top-up.
Full X problem caps remain **$0.10**. These resets do not reconstruct historic
remaining runtime budgets. At most 96 initial HTTP requests plus four requests
for the single separately audited infrastructure retry. Any retry shares its
cell's cumulative limit; no broad launcher retry flags are allowed.

Primary endpoint: paired all-cell total API cost C/F. Useful progress means
an actual generated continuation closes the original focused obligation,
or the complete proof verifies. Offline scoring replays the verified suffix,
tracks focus depth and unresolved existential names, and requires original
focus closure without fresh unresolved existentials. A fresh nested assertion,
shelving, state change or shorter goal list alone earns no progress. Unrecognized
focus/evar manipulation is conservatively unscored unless the whole proof
checks; report this limitation. Witness-enabled progress is a separate endpoint.
Local results are never qualified full-theorem solves; cost/qualified solve is
not applicable. Whole-proof acceptance within a reset is only descriptive.

Keep all expected cells, unsuccessful attempts, platform failures, budget stops,
censoring and unknown liabilities. Refuse expansion/ranking on incomplete panels.
Reprice receipt usage at receipt dates using the registered local rate table;
report cost, cost/useful, useful coverage, input/output/reasoning tokens,
requests, verifier elapsed time and RPC work together. Checkpoint data retain
F applicability even if the ordinary continuation cannot be admitted. Missing
phase results consume all their paid cost and earn no successful decision.

Practical primary gate: C executes four positives, abstains on both confirmed
negatives, makes useful continuation in amc12a_2003_p1 and imo_1983_p6, loses
no F useful cell, and saves >=15% in both total cost and cost/useful. Require
complete accounting and no unresolved platform failures/censoring/liability.
This practical gate is separate from two-sided family p<0.10 and descriptive
90% intervals. Six selected families are a small diagnostic sample. Do not
buy observations to reach significance. Repeated seeds and duplicate families
are one cluster, using the existing paired evaluator.

Terra compares TL/LM, TM/LM, TM/TL on supported decision correctness and cost
through the applicability phase; Holm adjusts the three comparisons for each
endpoint separately. Useful witness capability, executed corrections, explicit
abstentions, unknowns and tool use are descriptive. Neither a valid proposal
nor a verifier rejection is automatically a correct model decision. No adaptive
arm or teacher, and no model promotion from this diagnostic.
