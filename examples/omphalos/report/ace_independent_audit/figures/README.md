# Figure provenance

Each figure is supplied as PNG, SVG, and standalone PDF. Reproduce with `python -m experiments.ace_independent_audit.figures final` from `examples/omphalos`. The plotting code reads only this investigation's audited data files. Historical tariffs are normalized to 2026-09-19; fresh costs are reconciled receipts. Error bars cluster the two replicates by theorem; the accompanying JSON also reports broader proof-method-family sensitivity.
