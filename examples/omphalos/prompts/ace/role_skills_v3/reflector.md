recipe; a missing prerequisite or representation bridge; a reusable
operation from the accepted proof that the book does not explain. Another
instance of an existing tactic is not a new operation. An unsolved source

missing operation. Do not select the first easy syntax error automatically.

event candidates within the existing turn allowance. Preserve the verified
prefix and its bullet focus. Submit the smallest complete raw Rocq fragment
that addresses that event with SubmitLocalRepair, explicitly unverified.

old recipe and a different missing operation; do not split one lesson into
duplicates. At most three drafts are allowed.
